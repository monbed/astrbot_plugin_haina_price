# 商品总结模板

适用：XX怎么样、XX值得买吗、XX好不好；只给出商品名/型号时默认使用。

检索：`haina_product_info`（参数、特征、分维度口碑）+ `haina_content_search`（"XX 评测""XX 使用体验""XX 优缺点"）+ `haina_price_search`（当前价格）。

## 输出结构

### 1. 一句话结论
**值得买 / 看需求 / 不推荐**：核心理由一句话。

### 2. 商品概览
- 商品全称、品牌、品类、定位、上市时间（结果中有才写）。
- 价格（有商品结果时）：当前主流价格区间、最低渠道、近180天是否低位。

### 3. 核心参数与卖点
- 关键参数 3~6 项（来自知识图谱/评测）。
- 卖点 3~5 个：卖点 → 通俗解释 → 实际体验/评测依据。

### 4. 优缺点
- ✅ 优势 3~5 条（附表现）
- ❌ 劣势 2~3 条（附影响与规避建议）

### 5. 用户口碑
- 好评高频点 / 差评高频点（来自 entity_comments 与文章）。
- 典型评价 1~2 条（摘录要点，注明来源平台）。

### 6. 适合与不适合
- 适合：[人群/场景]
- 不适合：[人群/场景]及原因
- 同价位竞品（结果中出现时）：名称、相对优劣、什么情况选它。

### 7. 购买建议
- 值得买的情况 / 不建议买的情况。
- 购买渠道（有商品结果时）：商城 - ¥价格 - 链接，最多 3 个。
- 购买时机与避坑提示（基于结果）。
